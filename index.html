Golden Control — Suite hotelera

Ecosistema completo para un hotel: sistema de recepción, app para la gerencia y web para huéspedes.

Sistema de recepción (PC)
  • Habitaciones: apertura, cierre, limpieza y mantenimiento.
  • Caja diaria, consumos, clientes y reportes.
  • Roles de usuario y auditoría de cada operación.
  • Instalador para Windows, modo servidor o cliente en red.
App móvil de gerencia
  • Resumen del día, estadías, caja y 10 reportes.
  • Instalable en el celular con accesos directos.
  • Versión simple para el personal operativo.
Web para huéspedes (QR)
  • Un solo QR para todas las habitaciones.
  • Promociones, tarifas, carta de productos y membresía.
  • Buzón de sugerencias anónimo, términos y privacidad.
  • Material impreso generado desde la misma web: carta y carteles.

Lo uso a diario como gerente del establecimiento. Todo el ciclo, de la necesidad al soporte, pasa por mí.

En producciónGastronomía

Ramen App y Café Martica

Sistema de punto de venta para restaurante y cafetería.

  • Mesas, comandas a cocina o barra y PIN por mozo.
  • Caja, inventario, compras y clientes con puntos.
  • Factura electrónica SIFEN con firma digital.
  • Ventas en el celular, sincronizadas cada 5 minutos.

Un mismo núcleo sirve a dos negocios distintos, cambiando solo marca y menú. La nueva versión, en desarrollo, separa API y panel, vende sin internet y tiene pruebas automáticas.

Leite Business

Gestión financiera para negocios con varias unidades.
